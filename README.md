# OctBuildEx

OctBuildEx is an AIUX application for ServiceNow (scope `x_snc_octbuildex`). It includes a home page, a live incident list, a sample widget, and a few Fluent metadata examples. The UI is built with Lit web components, Tailwind CSS, and DaisyUI. The app is built and deployed with the ServiceNow SDK (`@servicenow/sdk`).

## Prerequisites

- **Node.js 24.14.1** (see `.nvmrc`; `package.json` requires `>=24.14.1`)
- **pnpm** (the lockfile is `pnpm-lock.yaml`)
- A **ServiceNow instance** (PDI or enterprise) and an account that can install applications

## Getting started

```bash
pnpm install
```

`pnpm install` also runs a `postinstall` script that copies the ServiceNow agent skills into `.claude/skills` and links them into `.agents/skills`. If the skills are missing, run `pnpm agent:skills`.

Connect the SDK to your instance. Credentials are stored locally in `.now-sdk/`.

```bash
npx now-sdk auth --add https://<your-instance>.service-now.com --type basic --alias <alias>
npx now-sdk auth --use <alias>
npx now-sdk auth --list
```

Then build and run:

```bash
pnpm build     # compile Fluent sources and the app
pnpm dev       # run the app locally against your instance
pnpm deploy    # install the app on the instance
```

## Scripts

| Command | What it does |
| --- | --- |
| `pnpm dev` | Runs `now-sdk run dev` |
| `pnpm build` | Runs `now-sdk build` to compile and validate sources |
| `pnpm deploy` | Runs `now-sdk install` to push the last build to the instance |
| `pnpm deploy:reinstall` | Same as `deploy`, using `--reinstall` |
| `pnpm lint` | Runs ESLint with the AIUX rule sets (a11y, i18n, style, SSR, app) |
| `pnpm doctor` | Runs `aiux doctor` to check the project setup |
| `pnpm agent:skills` | Re-copies the ServiceNow agent skills into `.claude/skills` |

Run `pnpm build` before `pnpm deploy`. If the build fails, the previous build output is still there, and deploying would push stale code.

## Pages and routes

Routes come from the `pages/` folder. The app's landing route is `/home` (see `aiux.json`). The navigation menu is set up in `application.js`.

| Route | Files | What it shows |
| --- | --- | --- |
| `/home` | `pages/home/page.js`, `pages/home/components/aiux-feature-card.js` | A starter landing page with feature cards and a link to the sample widget |
| `/incidents` | `pages/incidents/page.js`, `pages/incidents/url-sync.js` | An active-incident list using `aiux-list-connected`. Filter, view, sort, and split-view state sync to the URL, and long URLs collapse into a `sysparm_tiny` link |

The incidents page loads its data in a static `loader(ctx)` function. It reads the `sysparm_*` URL parameters, then fetches `incident` records. Its `url-sync.js` module has the URL logic.

## Widgets

`widgets/aiux-hello-world/` is a minimal AIUX widget. `index.js` renders a greeting. `server-script.js` adds the `greeting` and `timestamp` values to the widget data on the server.

## Fluent metadata

`src/fluent/` holds the `.now.ts` definitions that the SDK turns into ServiceNow records. The only file right now is `example.now.ts`. It defines:

- a **client script** on `incident` that shows an info message on form load
- a **business rule** on `incident` (after update) that calls `showStateUpdate` from `src/server/script.ts` and logs the state change

These records are installed on the instance when you deploy. Remove or change them before you deploy to a shared instance.

`src/fluent/generated/keys.ts` is generated by the build. It maps `Now.ID` keys to sys_ids, so commit it with your code.

## Configuration

- **`now.config.json`**: `scope` is `x_snc_octbuildex`. `metadataDir` is `src/plugin-xmls`, `appOutputDir` is `dist-metadata/app`, and `tsconfigPath` is `./src/server/tsconfig.json`. The SDK does not store instance connection details here. Those live in `.now-sdk/`.
- **`aiux.json`**: The `basename` (`octbuildex`) must match `package.json` `aiux.basename` when that is set.
- **`application.js`**: Sets the app theme, the navigation items (Home, Incidents), and the app title.
- **`.env`**: Local-only values (`GLIDE_ORIGIN`, `DEV_COOKIE`, `X_USER_TOKEN`). It is git-ignored. Don't commit it.

## Security

- The SDK keeps instance credentials in `.now-sdk/`. **This repo's `.gitignore` does not list `.now-sdk/` yet.** Add it before you commit anything, so credentials don't end up in source control.

## Development notes

- Components extend `AIUXElement` from `@servicenow/aiux/aiux-components-core`, not `LitElement`.
- Guard browser globals with `isServer` from `lit`.
- Use Tailwind and DaisyUI for styling. Don't use `--now-*` tokens.
- New user-facing strings go through `i18n.getMessage()`.
- For AI coding agents, follow [AGENTS.md](AGENTS.md).

## Troubleshooting

- **Skills missing after install:** run `pnpm agent:skills`.
- **Setup problems:** run `pnpm doctor`.
- **Deploy fails or pushes old code:** run `pnpm build` and fix any errors, then deploy again.
- **SDK questions:** `npx now-sdk explain developing-apps-guide` prints the SDK guide for this version. Use `npx now-sdk explain <topic> --list` to search other topics.
